# Manual do Usuário - Visual ERP

## 1. Primeiros Passos

### Login

1. Acesse o sistema pela URL fornecida
2. Digite seu email e senha
3. Clique em "Entrar"
4. Caso tenha esquecido a senha, clique em "Recuperar Senha"

### Recuperação de Senha

1. Na tela de login, clique em "Esqueci minha senha"
2. Digite seu email cadastrado
3. Verifique sua caixa de entrada
4. Siga o link para redefinir a senha

## 2. Navegação

### Menu Principal

- **Dashboard** — Indicadores e gráficos da empresa
- **CRM** — Leads, clientes, visitas, agenda
- **Projetos** — Projetos e ordens de produção
- **Orçamentos** — Criação e aprovação
- **Ordens de Serviço** — OS e acompanhamento
- **Financeiro** — Contas a receber/pagar, fluxo de caixa
- **Agenda** — Eventos e compromissos
- **Catálogo** — Serviços, categorias, materiais
- **Equipes** — Equipes e produtividade
- **Administração** — Configurações do sistema (admin)
- **Configurações** — Preferências da empresa

## 3. CRM

### Leads

1. Acessar CRM → Leads
2. Clicar em "Novo Lead"
3. Preencher dados de contato
4. Salvar

### Clientes

1. Acessar CRM → Clientes
2. Clicar em "Novo Cliente"
3. Preencher dados cadastrais
4. Salvar

### Visitas

1. Selecionar um lead ou cliente
2. Na aba "Visitas", clicar em "Agendar Visita"
3. Definir data, hora e responsável
4. Registrar resultado após a visita

## 4. Projetos

### Criar Projeto

1. Acessar "Projetos" → "Novo Projeto"
2. Vincular a um cliente
3. Definir nome, descrição, datas
4. Adicionar tarefas e equipes
5. Salvar

### Acompanhar

1. Acessar a lista de projetos
2. Clicar no projeto desejado
3. Visualizar status, tarefas, cronograma
4. Atualizar progresso das tarefas

## 5. Ordens de Serviço

### Criar OS

1. Acessar "OS" → "Nova OS"
2. Vincular a um projeto
3. Definir serviços, equipe, prazo
4. Salvar

### Acompanhar

1. Acessar a lista de OS
2. Visualizar status de cada ordem
3. Atualizar status conforme avanço

## 6. Produção

1. Acessar "Produção"
2. Visualizar ordens de produção relacionadas
3. Atualizar status (pendente, em produção, concluído)
4. Registrar horas trabalhadas

## 7. Financeiro

### Contas a Receber

1. Acessar Financeiro → Receber
2. Visualizar contas a receber
3. Registrar recebimentos
4. Acompanhar fluxo de caixa

### Contas a Pagar

1. Acessar Financeiro → Pagar
2. Visualizar contas a pagar
3. Registrar pagamentos

### Fluxo de Caixa

1. Acessar Financeiro → Fluxo de Caixa
2. Visualizar entradas e saídas por período
3. Analisar saldo atual e projetado

## 8. Agenda

1. Acessar "Agenda"
2. Visualizar eventos por dia, semana ou mês
3. Criar novo evento
4. Vincular clientes, projetos ou OS

## 9. Dashboard

### Visão Geral

- **Comercial:** Leads, clientes, orçamentos
- **Produção:** OS ativas, taxa de conclusão
- **Financeiro:** Faturamento, contas a receber/pagar
- **Operação:** Indicadores de performance

### Gráficos

- Receita por mês (gráfico de barras)
- Orçamentos por status (gráfico de pizza)
- Produção por departamento (barras)
- Funil comercial
