# Release v1.0.0 — Visual ERP

**Data**: 2026-07-25

## Resumo

Primeira versão de produção do Visual ERP, um sistema ERP completo para gestão empresarial com 29 módulos integrados, multi-tenant, RBAC, e arquitetura moderna Next.js.

## Novidades

### Módulos Core
- **CRM**: Gestão de leads, visitas, pipeline comercial
- **Projetos/OS**: Ordem de serviço completa com timeline, anexos, eventos
- **Produção**: Painel de produção, departamentos, ordens de produção
- **Financeiro**: Contas a pagar/receber, fluxo de caixa, dashboards
- **Agenda**: Calendário com visões mensal/semanal/diária
- **Catálogo**: Serviços, categorias, subcategorias, componentes
- **Equipamentos/Materiais**: Cadastro completo com categorias
- **Instalações**: Agendamento, equipes, veículos, entregas

### Módulos Avançados
- **Comunicação**: Omnichannel com conversas, inbox, templates
- **Builder**: No-code para criar entidades e formulários
- **Jobs/Filas**: Processamento assíncrono com scheduler e retry
- **Segurança**: Auditoria, compliance, políticas, governança
- **Plataforma**: Super admin SaaS, licenciamento, billing

### Infraestrutura
- **DevOps**: Observabilidade, health checks, logging, deployments
- **AI**: Chat, prompts, provedores, embeddings
- **Workflows**: Automação com triggers, ações, condições
- **Plugins**: Engine para extensões, marketplace
- **Knowledge**: Base de conhecimento, busca semântica
